DropLAN is basically a file sharing system that using a LAN(Local Area Network) to share text and files to other people
Basically it gives you two options at the beginning
1. You can either create a room or join a room 
If you create a room you would eventually act as a Server and it would generate a 6 digit room code
2. You can join a room where you would act as a client where to join a specific room you need the room code of that particular 
room
